# Документация

- [GAME_DESIGN.md](GAME_DESIGN.md) — механика, трасса, экономика, решения.
- [ARCHITECTURE.md](ARCHITECTURE.md) — деплой, скрипты, ремоуты, данные.
- [PLAYBOOK.md](PLAYBOOK.md) — как из этого движка собрать похожую игру (вода, суша): все шаги.
- [TEAM.md](TEAM.md) — агенты-роли (трассы, правила, дизайн, тест, ревью) и как проходит задача.
- [BUSINESS.md](BUSINESS.md) — как игра зарабатывает: экономика Roblox, воронка и KPI, лестница монетизации, привлечение, гипотезы.
- [IDEAS.md](IDEAS.md) — бэклог идей с оценкой польза/цена/риск и статусами.
- [ENGINEERING.md](ENGINEERING.md) — инженерный стандарт: Luau, паттерны проекта, где искать документацию, инструменты проверки.
- [TESTING.md](TESTING.md) — как проверять на staging, что считать сложностью, формат бага.
- [CHANGELOG.md](CHANGELOG.md) — что и когда сделано.
- План по эпикам и задачи — GitHub issues #1–#12.

Правило: каждое изменение игры сопровождается записью в CHANGELOG и, если меняется механика или
устройство, правкой GAME_DESIGN / ARCHITECTURE.
