# Тестирование на staging

Как проверять игру без Studio: деплой на тестовый плейс, вход через клиент Roblox на компьютере
владельца, прохождение, логи. Это рабочая инструкция агента `qa-tester`; людям тоже подходит.

## 1. Убедиться, что проверяешь нужную сборку
```bash
H=$(git rev-parse --short HEAD)
until s=$(gh api "repos/vdmemory/sled-game/actions/runs?per_page=3" \
  --jq '[.workflow_runs[] | select(.head_sha[0:7]=="'$H'")][0] | "\(.status) \(.conclusion)"'); \
  [[ "$s" == completed* ]]; do sleep 10; done; echo "$s"
```
После `completed success` старые серверы живут ещё ~30–45 с. Клиент, который уже в игре, остаётся
на старом сервере — нужно выйти и зайти.

## 2. Управление клиентом Roblox (macOS владельца, кадр 1372×891)
Только после разрешения владельца (`computer_request_full_control`). Клики: `mouse_move` дважды →
`left_mouse_down`/`left_mouse_up` (одиночный `left_click` иногда теряется). Окно Roblox ≈
x 50–1310, y 40–870. Фокус — клик по заголовку окна (600, 46).

| Действие | Где |
| --- | --- |
| Меню Roblox | Escape; **Leave** (440, 770) → Return для подтверждения |
| Play на странице игры | (632, 397); уведомление «Continue» в плейтесте — (184, 248) |
| Начать заезд | (608, 612) или (608, 563); рогатка — держать Space 1.5 с |
| Ракета в заезде | (130, 790) |
| Плитки лобби (x ≈ 106) | миры 218, задания 304, сани 392, следы 478, подарки 566 |
| Шестерёнка / DEV | (1100, 212) / (1262, 255) |
| Консоль | F9, вкладки Client / Server; закрыть — снова F9 |

Системное уведомление macOS (UserNotificationCenter) может перекрывать клики — попросить владельца
закрыть. По окончании: `computer_release_full_control`, затем `computer_release_lock`.

## 3. Панель владельца для тестов (DEV)
Только для `UserId == CreatorId`. Вкладка **Инструменты**: поставить уровень, выдать монеты/гемы,
уровень апгрейда, сани, сбросить задания. Вкладка **Настройка**: любой параметр из
`Config.TUNABLES` на лету (применяется у всех, сохраняется в DataStore). После экспериментов —
«ВСЁ ПО УМОЛЧАНИЮ» + «СОХРАНИТЬ ДЛЯ ВСЕХ». «ТЕСТ МИРА» в окне миров — фарм любого мира.

## 4. Что считать сложностью
Для уровня N (всё из `Config`):
- длина `levelLength(N)`, крутые участки `steepChance(N)`, дороги `roadCount(N)` в точках
  `ROAD_AT`, машин на полосу `carsPerLane(N)`, скорость машин `CAR_SPEED`;
- препятствий: `OBSTACLE_ROWS` рядов на прямой сегмент, `LANES` полос, свободно ≥ 2;
- скорость игрока: `maxSpeed(tier саней)`, старт `launchSpeed(tier рогатки)`, ракета
  `rocketFuel`;
- ожидаемое время ≈ длина / (0.7 · maxSpeed); «плотность» = препятствий на 100 studs.

Норма: первый уровень мира — 1–2 попытки на среднем апгрейде мира, пятый — 3–5. Ряд без
свободной полосы, машина, которую нельзя объехать, трамплин, с которого не долетаешь при
`RAMP_MIN_SPEED`, — баги генерации (к `track-architect`).

## 5. Чек-лист прогона
- [ ] `gh run` зелёный, вход без ошибок в F9 (Client, Server)
- [ ] лобби: валюты, плитки, окна миров/заданий/саней/следов/подарков, настройки
- [ ] заезд: рогатка, руль, ракета, флип, монеты подбираются, бонусы (щит, x2, канистра, кольца,
      магнит, кристалл), авария ragdoll, финиш и озеро, экран итога
- [ ] уровни: 1, 5 (конец мира), первый уровень следующего мира, фарм
- [ ] задания засчитываются, сундук, подарки, сундук лобби
- [ ] апгрейд → новый тир → анимация reveal, вид рогатки/саней/ракеты меняется
- [ ] покупка саней/следа, надевание, вид в лобби и заезде
- [ ] выход-вход: прогресс на месте
- [ ] F9 после всего: ни одной красной ошибки
- [ ] телефон (если есть): FPS, кнопки, читаемость

## 6. Формат бага
**Шаги** · **Ожидалось** · **Факт** · **Где** (файл/функция из лога) · **Серьёзность**
(блокер / серьёзный / косметика) · скриншот. Баги не чиним — передаём профильному агенту.
