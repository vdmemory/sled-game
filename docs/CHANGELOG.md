## Технический блок перед релизом (#22, #21, #32, #20, #19; code-reviewer, game-designer)
- **#22 CI не молчит.** `publish.sh`: загрузчики ассетов возвращают код 3 при неполной загрузке →
  аннотация `warning` + строка в Summary («в игре эмодзи/Part/встроенные звуки»); новые ID → пересборка,
  rojo ищется в PATH → `.tools/bin` → `$RUNNER_TEMP` (нет — ставится `check.sh --install`); пересборка
  не удалась → публикация отменяется (раньше молча уходил старый `game.rbxl`); новые ID не закоммичены →
  JSON в лог и Summary, job красный после публикации (`ASSET_IDS_UNCOMMITTED_OK=1` — только warning), чтобы
  ID не загружались заново на каждом деплое (аудио — 10/мес). Нет `game.rbxl` — `publish.sh` собирает сам.
  HTTP-повторы с паузой 2/4/8 с: GET при 0/429/5xx, POST создания ассета — только 429/503 (без риска
  дубликата); статус модерации — без повторов. `check.sh` качает инструменты с `--retry 5
  --retry-all-errors`. `fetch_metrics.py`: доли по объявленному формату (`analytics/config.json` →
  `rate_format: percent`; 0.8 → 0.008), а не по `v > 1`; сеть/таймаут/не-JSON → `(0, error)` с повторами.
- **#21 Выход посреди заезда.** `PlayerRemoving` и `BindToClose` (до сохранения) идут через общий
  `endRun(player, reason, leaving = true)` (`Runs.onLeave` / `Runs.endAll`): в полёте — `"left"`,
  после арки — `"finish"`, после аварии — `"crash"`, у рогатки — `"back"`. Начисление, задания, рекорд,
  экономика и лидерборд недели — как у обычного конца заезда, без финиш-бонуса; без окна итогов и
  паузы (санки/трасса/слот убираются сразу). Новое событие `RunLeft` (% трассы, 0 — у рогатки).
  Падение `endRun` не мешает уборке и `Data.release`.
- **#32 Задания дня — только выполнимые.** `shared/DailyTasks`: общий набор дня + для игрока
  понижение цели или детерминированная замена невыполнимого (`Config.taskAvailable`: `needWorld`,
  `needLevel`, `needRare`, `needSpeed`, `need(d, target)`); номер слота сохраняется. Набор игрока —
  в сейве `Daily.set`, перепроверка при входе (полученные слоты не трогаются; старые сейвы без `set` —
  общий набор дня + замена). farm — с мира 2, speed — по потолку «Саней», rareRuns — при Gold, buySled —
  с уровня 3 (`TASK_BUYSLED_LEVEL` в TUNABLES), combo 8–20 → 5–15. `Config.KMH_PER_STUD`. Стенд
  `scripts/stand/daily_tasks.luau`: 60 дней у новичка — 0 невыполнимых.
- **#20 Простой у рогатки.** Heartbeat: не выстрелил за `Config.IDLE_LAUNCH_TIMEOUT` (60 с, TUNABLES
  «Трасса», 0 — выкл.) → `endRun(player, "idle")`: тихий конец как BACK (без наград/статистики), санки,
  трасса и слот освобождаются, персонаж в лобби; клиенту `RunEnded {reason = "idle"}` → сообщение

  санки бесконечно. Проверки «тихих» причин в `endRun` сведены к одному `quiet`.

## Исправлено: вылет за карту у дороги и «на старте без персонажа» (#50, P1; track-architect + game-designer)
- **Дыра у дороги.** У ледяного жёлоба поворотов невидимых бортов нет — сани выезжают на ледяную
  стенку и на выходе из поворота (или после трамплина) оказываются снаружи борта, на сугробе. У
  дороги и переезда (`ROAD_PROFILE`) сугроба не было, `Ground` без коллизий, барьер у самого края
  дна — снаружи борта пустота: падение за карту (чаще всего у левого/правого края дороги сразу
  за поворотом). Фикс `Track/Sections`: у дороги/переезда снаружи борта — невидимый сугроб профиля
  снежного куска и барьер там же, где у него (видимая дорога, машины, знаки — без изменений); у
  озера за бортом — поперечный барьер (там был карман, обрывавшийся назад в пустоту).
- **Проверка бортов** `scratchpad/walls/` (стенд шимов Roblox API, как в #40/#33): все куски
  уровней 1–50 (419 496 рядов по 1.5 stud), ячейки x = 36…80 с каждой стороны: «стена»
  (Wall/Barrier/EndWall), «опора» (верх Floor/Bank/Ramp/Part вдоль нормали куска) или пусто;
  заливка от края дна, дыра — пустая область шире 4.5 studs, соседняя с достижимой опорой
  (пропасть островков — намеренная). Было: 385 мест (дороги 260, переезды 20, край озера 100, прочие 5),
  стало: 0. Гладкость ходовой части (проверка #40) — без изменений (0 нарушений).
- **«На старте без персонажа, только сани».** `endRun` снимал `ending` до `LoadCharacterAsync`
  (yield): тап «Играть»/зона посадки во время загрузки персонажа начинали новый заезд со старым
  персонажем, он тут же удалялся — игрок видел рогатку и пустые сани, заезд висел (до выстрела

  игрок в `ending`, проверка «упал с лобби» его не переносит (PivotTo уносил в лобби и сани);
  сторож в Heartbeat: персонаж заезда удалён/пересоздан/мёртв или не сидит в санках дольше
  `RUN_UNSEATED_MAX` (2 с) → `endRun("left")`; `startRun` требует HumanoidRootPart; клиент на
  новом персонаже бросает старые санки (камера не остаётся на рогатке). Все концы заезда
  (finish, crash, fell, stopped, cheat, left, back, restart) идут через один путь.
- **Страховка — мягкий возврат** (идея #19): ниже дна куска на `RESCUE_DEPTH` 12, дальше барьера
  (`RESCUE_SIDE`) или дольше `RESCUE_OUT_TIME` 1.5 с снаружи борта → ремоут `Rescue` (сани на дно

  сучком и камнями → стальной кнехт с фланцем и болтами → розовая колонна с каннелюрами и капителью
  (как в оригинале) → гидравлический столб с «зеброй», хромированным штоком и лампой → золотая
  колонна на мраморе со спиралью и камнем → неоновый обелиск с парящим кристаллом. Сверху намотаны
  витки резинки; резинка «витая» (полосы вдоль луча), цвет по тиру.
- **Ракеты**: ступенчатый корпус, хомуты с заклёпками, иллюминаторы, гоночная полоса,
  воздухозаборники, сопло-колокол с огоньком, крупные стабилизаторы с законцовками.
- **Сани**: у ватрушки шов, резиновый пояс и эмблема; у деревянных — болты, стальные уголки,
  задний бортик; у доски — пряжки, болты, стомп-пэд; у самолёта — навигационные огни, патрубки,
  антенна, спинка кресла. Спойлер (тир «Саней») — с синими торцевыми пластинами, как в оригинале.

### Анимация прокачки, ракеты, музыка
- **Анимация нового тира** (как «GOT AERO TAIL!» в оригинале): когда рогатка, сани или ракета
  выходят на новый тир — вспышка, затемнение, вращающиеся лучи, 3D-модель новой детали с облётом
  камеры, искры и большая надпись «ПОЛУЧЕНО: …!». Закрывается кнопкой «ОТЛИЧНО!», тапом или сама
  через 5 с. Обычный уровень — «пружинка» карточки и звук. Код: `client/Reveal.client.luau`.
- **6 дизайнов боковых ракет** по тиру апгрейда «Ракета»: петарда с фитилём → красная ракета с
  синими стабилизаторами → серебристая турбо → сине-белая «мега» со светящимся соплом → золотой
  «бласт» → тёмный «гиперджет» с неоновыми крыльями. Ракеты стоят на всех санях (на самолёте —
  на крыльях), огонь бьёт из их сопел.
- **Обвес по тиру «Саней»**: фары → спойлер → обтекатель → золотая отделка → неоновая подсветка
  (раньше «боковые ускорители» — теперь ракеты отдельно у апгрейда «Ракета»).
- **Фоновая музыка**: тихий трек по кругу, в заезде тише; кнопка «Музыка» в настройках.
  Если аудио-ID недоступен — играет тихая «музыкальная шкатулка» из встроенного звука.
  Свой трек — `Config.MUSIC_IDS`.

### Интерфейс, модели саней, лобби
- **Доводка** (`4905f27` и далее): глянцевые редкости вместо «мятой фольги», Galaxy светится
  только акцентами, лишний декор тиров убран с доски/санок/самолёта; кто упал с площадки лобби —
  возвращается на точку появления; таймер магнита сбрасывается в новом заезде.
- **Документация**: `docs/GAME_DESIGN.md`, `docs/ARCHITECTURE.md`, этот журнал; прогресс по эпикам —
  в плане (Claude Docs) и в issues.
- **Детализированные 3D-сани** (`e87e530`): ватрушка-тюбинг (гладкий тор, полоска, ручки, клапан),
  деревянные санки (загнутые стальные полозья, стойки, рейки, дуга-руль, верёвка), сноуборд
  (поднятые нос и хвост, кант, рисунок, крепления), сани-самолёт (фюзеляж, кабина, крылья с
  кругами, хвост, пропеллер, лыжи на стойках). Редкость перекрашивает модель. Те же модели — на
  подиумах лобби.
- **Мостик → старт трассы** (`e87e530`): мостик лобби ведёт к краю склона, за ним видна
  «витринная» трасса. Шагнул на светящееся кольцо — садишься в сани у рогатки. Лобби отодвинуто
  от трасс игроков. Старт тапом по всему экрану убран (мешал ходить на телефоне).
- **Убраны**: билет дня (скретч-карточки) и иконка пингвина — по решению владельца.
- **Рестайл всего интерфейса под мобильный оригинал** (`4990725`, `87e14f3`, `2e9c329`): общий
  модуль `UIKit`; лобби с «УРОВЕНЬ N», жёлтой плашкой сундука, плитками-иконками, «НАЖМИ, ЧТОБЫ
  ИГРАТЬ», тёмными карточками апгрейдов; HUD заезда; полукруглая шкала рогатки; экран «Ты получил»
  с кнопкой «ПРОДОЛЖИТЬ»; все окна в голубом стиле с лентой и круглым крестиком.
